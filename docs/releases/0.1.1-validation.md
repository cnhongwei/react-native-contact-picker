# 0.1.1 release validation

Validated on 2026-10-20 using Node.js 24.13.0, React 19.3.0 and React Native 0.88.0.

## Package isolation

- Built the library with `yarn prepare` and created the archive with `npm pack --ignore-scripts`.
- Created a standalone consumer outside the repository from the example's native app scaffolding.
- Removed the workspace Babel/Metro configuration and explicit local dependency override; used the default React Native Babel preset and Metro configuration.
- Installed the `.tgz` through npm into the consumer's own `node_modules`; it was not a symlink.
- Confirmed every installed package file matched the archive and that the default JavaScript entry resolved to `lib/module/index.js`.
- Confirmed Android and iOS autolinking paths referred exclusively to the installed package.

## Results

- TypeScript, ESLint and all four JavaScript API tests passed.
- Android: `:app:assembleRelease` with `arm64-v8a` succeeded, including Codegen and JS bundling. Installed and launched `contactpicker.tarballverify` on the running Android emulator; the selection button and initial status rendered correctly.
- iOS: `pod install` and an unsigned arm64 simulator Release build succeeded. Installed and launched `contactpicker.tarballverify` on iPhone 16 Pro / iOS 18.5. Selected Alice Test's work number and observed `Alice Test: +1 202-555-0103`; reopening and cancelling preserved the selection and displayed the cancellation status.
- Both Release apps contained embedded JavaScript bundles and did not depend on Metro.
- Android declared no READ_CONTACTS/WRITE_CONTACTS permission; the iOS app had no NSContactsUsageDescription.
- The previous implementation validation also passed 10 Android Robolectric tests and GitHub CI at commit `d877432`.

## Scope

This release check covers the packaged library in an independent native consumer. The Android picker interaction was not repeated in this standalone consumer. Physical devices, additional Android contact providers, and other React Native versions remain outside this verification scope.
